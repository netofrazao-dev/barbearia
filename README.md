# 💈 Barbearia - Template de Site

## 📌 Sobre o projeto

Este projeto é um **template de site para barbearias**, desenvolvido com foco em apresentar serviços, estilo visual moderno e facilitar o contato com clientes.

É um modelo estático, ideal para quem deseja personalizar e utilizar como base para projetos reais.

---

## 🚀 Tecnologias utilizadas

* HTML5
* CSS3
* JavaScript

---

## ✨ Funcionalidades

* 📸 Galeria de fotos (cortes de cabelo e barba)
* 📍 Seção com localização da barbearia (mapa integrado)
* 📞 Informações de contato
* 📝 Formulário de contato
* 📱 Design responsivo (adaptado para mobile, tablet e desktop)

---

## 📱 Responsividade

O layout foi desenvolvido para funcionar bem em diferentes tamanhos de tela, garantindo uma boa experiência tanto em dispositivos móveis quanto em desktops.

---

## ⚠️ Aviso

Este projeto é apenas um **modelo/template** e não representa uma barbearia real.
